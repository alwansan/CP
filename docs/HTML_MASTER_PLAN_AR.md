## Backend والـbridge
Native مصدر الحقيقة، لا طابور موازٍ ولا persistence إنتاج في localStorage. الحفاظ على Queue110/MkvExporter/MkvReconciler/Restart108/RecoveryCapsule/Lease115 و3 shared slots وLocalAccountStore. DownloaderService foreground dataSync، لا android:process ظاهر له؛ افحص حدود العملية قبل تغييرها. استقلال عمر الواجهة لا يعني CPU/RAM معزولة أو استمرار بعد force-stop الحقيقي؛ استرداد مؤكد عند إعادة التشغيل.
رسائل versioned {v,requestId,action,args}؛ allowlist وvalidation origin/mainFrame/IDs/types/size؛ ACK دائم بعد قبول وتثبيت native (ليس مجرد وصول رسالة)، نتائج لكل item في batch، idempotency، snapshot(revision,epoch)/delta(baseRevision,revision,seq)، replay/gap reconcile/paging، cancellation من native. لا raw DB/signed URLs/keys/local account files في JS. DB/network/mux/serialization ثقيل بعيداً عن main، coalesce deltas 100–250ms مبدئي قابل للقياس؛ no full refresh، bounded DOM/virtual list. لا سرعة المحرك مرتبطة بالأنيميشن.
WebViewAssetLoader HTTPS local origin وWebViewCompat.addWebMessageListener إن توفرت، feature detection؛ جرد tree لم يجد androidx.webkit المذكورة بالاسم، تحقق dependency/DEX budget قبل إضافة pinned library أو بديل آمن. حظر navigation خارجية وiframes وfile universal access، CSP local، safe DOM، قيود rate/payload، no unrestricted JS interface. onRenderProcessGone يعيد إنشاء العرض والاتصال دون إلغاء الأعمال. File picker وbackup native. targetSdk29 مثبت في apktool.yml؛ لا تغيره الآن؛ راجع Android 15 dataSync timeouts عند target35.
