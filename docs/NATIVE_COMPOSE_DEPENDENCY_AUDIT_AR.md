# CP native Compose — integration collision inventory
Audit only; no APK merge. Compare verified cp-compose-lab-5 bytes (fixed SHA256) against every original smali root plus res/values/public.xml. Read compiled DEX class definitions with Android dexdump; read compiled resource name/ID map via aapt2. Reports exact descriptors, resource names, differing IDs, duplicate definitions and same numeric resource IDs with different names. Raw collision is NOT proof of binary incompatibility or equivalence. A name overlap is evidence that blind concatenation must stop, not instruction to remove original AndroidX/Kotlin classes. Need method/field ABI compatibility, transitive dependencies, resource ID relocation/stability, manifests/providers and signed ART regression before any merge. Resource audit restricted original public.xml (not full all private/variant values). Lab #5 chosen verified published build; later shell variants may differ. No original app changes.
