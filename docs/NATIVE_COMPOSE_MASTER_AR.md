## الهدف
واجهة Android Native خفيفة، مستقلة منطقياً وعبر عملية منفصلة عند إثبات بوابة startup. لا WebView في الواجهة الجديدة، لا قراءة مباشرة لملفات/DB/شبكة/FFmpeg على UI، لا انتظار محرك synchronous. عزل عملية الخلفية ليس حجزاً للCPU/GPU/RAM/I/O، لذا قياس حقيقي للضغط شرط. مصدر الحقيقة يبقى المحرك الأصلي.
## معمارية التنفيذ
- UI: Kotlin + Jetpack Compose, immutable/small screen state, stable IDs, lazy list/row; route-scoped collectors, latest-state coalescing, navigation state and cancel stale reads. Reuse previous design tokens Obsidian #090A0D, panel #17191E, ivory #F8F4EE, coral #FF856C; Eco solid default, finite motion and user control. No continuous blur; optional verified native AGSL later.
- Bridge: reuse pure Java models in patches/html-bridge; native typed commands/read-only owner service + bounded page cursor; IPC async and no reenqueue on renderer restore. No generic command endpoint; durable receipt gate required for writes; resume mapping still unresolved.
- Engine: existing main process owner + :filedownloader; preserve existing jobs and MKV 3 slots. Explicit process startup protection before Dagger/LocalRuntime/Restart108; pure classifier now targets exact :nativeui in new branch, legacy :htmlui is UNKNOWN; actual Android startup/manifest changes remain gated, no blind inheritance changes. Optional nonexported activity/service and original signed ART; no old UI deletion pending route parity.
