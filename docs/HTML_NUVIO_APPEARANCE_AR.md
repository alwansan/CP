## CP appearance system (proposed; base implemented in isolated lab)
Navigation logical stable home/categories/search/downloads/account; RTL mirrors physical positions; center search; actual navigation only once at tap or drag release; vertical gestures win, cancellation restores prior destination, rapid taps/resize must settle. Adaptive = compact on scroll down, expands on scroll up/top; Expanded always labels; Compact icons only with aria labels; Classic rectangular, all labels. Live preview. Initial ranges subject to device measurement: width 72–100%, height 56–84 CSS px with min touch slot 48, icon 18–30, label 10–14, corner 12–40, text 90–140%, motion duration multiplier 50–150%, glow switch, accent color; font system/Tahoma-Arial/serif fallback. Production later: choose bundled Arabic/Latin fonts after license/readability, safe native import if desired, no network font URLs; respect OS font scale/TalkBack. UI prefs separate from download/DB settings, native persistence schema version and clamp/migrate/default/recovery. Preset import/export optional no secrets. Preview/reset per section, no page reload.
Home customization: enable/reorder shelves with grab handle and accessible up/down, custom title, hero on/off/autoplay delay with reduced motion, Continue Watching styles/visible only if data, posters ratio/width/spacing/radius/metadata/edge, details layout/blur/badges, choose per-page density; fonts/size/style/color global then local override. Do not hide necessary controls, distinguish hide section from delete history. Existing playback/subtitle settings independent. Full matrix in master plan.
