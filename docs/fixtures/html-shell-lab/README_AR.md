# مختبر الهيكل الموحد — CP-DL

نموذج مستقل يجمع التبويبات الخمسة والصفحات الفرعية والحركة والتخصيص في تطبيق واحد. بيانات الأفلام والتنزيلات اصطناعية بالكامل. لا يتصل بحساب المستخدم أو بقاعدة البيانات أو بخدمة التنزيل والتحويل.

## تشغيل الاختبار
```sh
npm install --no-save --package-lock=false playwright@1.51.1
npx playwright install chromium
node test-browser.cjs
```

## التغطية
- الرئيسية، الأقسام، البحث، التحميلات، الحساب بترتيب RTL.
- البحث النصي وفلاتر الأفلام والمسلسلات، تفاصيل المحتوى وقائمة خيارات الملصق.
- عناصر ومجموعات التنزيل التجريبية، صفحات الإعدادات والمظهر.
- dark/light/OLED، لون accent، حجم وشكل الشريط، glass/motion وثلاثة أشكال لمتابعة المشاهدة.
- حفظ تفضيلات العرض في localStorage للمختبر فقط، Escape/Back، widths متعددة.

## حدود مهمة
لا Android WebView ولا Native bridge ولا مصدر محتوى أو تنزيل فعلي ولا تشغيل فيديو. لا تستخدم بيانات النموذج كحالة إنتاج. يجب ربط كل مسار بعقد Native مصادق عليه، ACK دائم، واختبارات تكافؤ قبل استبدال أي واجهة قديمة.
