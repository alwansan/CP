# PATCH262 — الحذف وأكمل المشاهدة

قاعدة التعديل: `565fd1cf`، فرع `fix/download-mkv-self-repair`.

## نتيجة مراجعة الجهاز والسجلات

- المستخدم أكد تحسن الاستعادة، والسجلات الأحدث في CL تسجل تثبيت حلقات مكتملة.
- صورة التعطل تحدد IllegalAccessError للحقل Ui7.app عند استدعائه من kw0$l، وهو مسار تنظيف أضيف في PATCH261. جعل الحقل public يصلح الخطأ المحدد، وأضيف اختبار سلبي يثبت أن فحصنا يرفض رجوعه لصلاحية محلية.
- ربط الضغط المطول السابق محصور بشريط الرئيسية، ويحذف مباشرة؛ صفحة المزيد لا تحمل الربط.

## أكمل المشاهدة

- تنظيف لاحقة S01 أو S01 E29 من عنوان العرض فقط؛ لا تعديل لهوية الحلقة ولا لبيانات الملف أو اسمه.
- قائمة صغيرة مثبتة بالغلاف، بمؤشر وأيقونتي التفاصيل والحذف، تعمل في الرئيسية وصفحة المزيد.
- التفاصيل تستعمل نسخة مستقلة من نموذج الحلقة ومعرف rootSeries عند توفره، وتستعمل مسار التنقل الأصلي. اعتراض تشغيل المتابعة يعطل مؤقتا أثناء طلب التفاصيل فقط.
- أيقونة حذف بصفحة المزيد تبدأ وضع تحديد محلي لسجل المشاهدة: تحديد مفرد، الكل، إلغاء الكل، عمل، موسم، ونطاق حلقات ضمن عمل وموسم محددين، ثم تأكيد الحذف أو إلغاء الوضع.
- إزالة السجل تستعمل removeOnly الأصلية حتى تكتم جلسة تشغيل نشطة وتمنع عودة العنصر مع نبضة التقدم التالية. لا تحذف فيديو أو ترجمة أو صف تنزيل.
- تنظيف أدوات الصفحة عند onDestroyView؛ ربط العناصر المعاد تدويرها يعاد ضبطه عند كل bind.

## حذف التحويل المنتظر أو الجاري

- إتاحة اختيار MP4 وMKV والمؤقت داخل زر حذف التنزيلات.
- قبل حذف أي ملف، تحفظ نية حذف على القرص وتحدث request epoch. يوقف التنزيل الأصلي إذا كان ما زال نشطا.
- تزال مهمة التحويل من طابور Executor فقط إذا لم تبدأ؛ لا تزال علامة ملكية عامل جار بالقوة.
- يسجل FFmpeg حسب هوية الحلقة، ويوقف process الخاص بها، ثم ينتظر عامل الحذف تحرر ملكية التحويل وانتهاء تحديثات العامل الأخيرة.
- فحص الإلغاء عند بدء العامل وعند تسجيل process وقبل نشر الناتج يمنع تثبيت عمل قديم بعد الحذف.
- عند تعذر الإيقاف خلال المهلة، يحتفظ بالملفات ويعيد خطأ قابلًا للمحاولة؛ لا يحذف ملفات تحت عامل حي.
- المؤقت mp4.temp وملفات mux part المطابقة والنسخ الاحتياطية تضاف إلى سجل الحذف الأصلي، وتخضع لفحص المسار والتعارض الموجودين فيه. لا يضاف مؤقت تابع لحلقة أخرى.
- إن اكتمل التحويل أثناء انتظار الإلغاء، يستخدم مسار الحلقة الحالي من قاعدة البيانات بعد ثبوت الهوية ونية الحذف.

## التحقق

- 18 تحققًا سلوكيًا على كود Java الفعلي: تنظيف العنوان مع إبقاء عناوين أصلية، إلغاء طابور، إيقاف process، منع تثبيت متأخر، وحصر المؤقتات.
- 3 اختبارات إضافية لفحص الربط: رفض الحقل غير المتاح، رفض hook مفقود، وعدم تكرار الأصناف المنقولة بين ملفات DEX.
- اختبارات الاستعادة الخمسة السابقة وفحوص الروابط/الحقول/سجلات الاستدعاء.
- بناء apktool كامل محليا؛ نقل i42 وn54 إلى DEX6 بسبب امتلاء DEX الأول، مع ثبات الأسماء والمسارات البرمجية.
- بناء وتوقيع GitHub Actions مطلوبان للإصدار. هذه الفحوص لا تمثل اختبار واجهة Android أو ART أو عملية FFmpeg على هاتف. يلزم اختبار القوائم، التنقل للتفاصيل، التحديد، وحذف تحويل فعلي على الجهاز.
