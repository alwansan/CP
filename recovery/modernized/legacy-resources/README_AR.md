# وحدة موارد سينمانا الأصلية — تجربة مستقلة

الهدف هو قياس إمكانية استعمال مجلد `res` و`assets` المستخرج من APKTool مباشرةً في مشروع Android Gradle بدل إعادة كتابته.

تحتفظ الوحدة بالموارد الموجودة فعلياً تحت `Cinemana_PATCH252_Project/app/res` وملفات الأصول تحت `app/assets`، ولا تغيّرها.

اسم مساحة الموارد `com.cinemana.pro` لمطابقة الأصل.

هذه وحدة AAR لا تحتوي `Activity` أو واجهة إطلاق فعلية. عدم نجاح بناء الموارد يعني أن ملفات APKTool تحتاج تحويل أو معالجة، وليس أن ملفات Smali الأصلية تالفة.
