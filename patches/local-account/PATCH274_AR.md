# PATCH274 — دقة صور الإشعارات

استقرار الصور تأكد من تجربة المستخدم على PATCH273؛ انخفاض الجودة سببه اختيار imgThumbObjUrl الصغير كمصدر أساسي. بطاقة الإشعار الآن تفضل imgMediumThumbObjUrl الموجود فعلياً بنموذج المحتوى. إذا غاب تستخدم الصورة الأصلية، وتبقى imgThumbObjUrl كطلب أولي سريع وبديل واحد عند فشل الصورة النهائية عبر callback c المصحح. لا تُخمن روابط أو تُحمل صور بلا حد، ولا تتغير بيانات الحساب أو مواعيد الفحص.

التحقق: مطابقة حقل imgMediumThumbObjUrl بكلاس VideoModel الأصلي، اختبارات الحساب والجسر وحارس المراجع، بناء APK وفحص جميع DEX والتوقيع وCI. وضوح الصورة النهائي على الهاتف يحتاج تجربة المستخدم. النشر APK مباشر عبر Release مستقل.
