# بروتوكول CP-DL
بداية كل جلسة: اقرأ AGENTS وRESTORE والذاكرة والحالة والخطة والمشاكل وأحدث سجل؛ راجع HEAD الحي وActions وCL. سجّل origin=chat أو schedule فقط عند وجود مهمة فعلية، session_id، الوقت، HEAD، هدف المالك ونطاق التغيير.
أثناء العمل: حدّث سجل الجلسة وSTATE عند كل دفعة ونتيجة، بما فيها الفشل. أضف المعرفة المثبتة إلى MEMORY وحدّث PLAN وISSUES وRESTORE بنقطة الاستئناف. احفظها في GitHub مع الدفعة أو commit لاحق للنتيجة. لا تنتظر طلب «حدث الذاكرة». لا تخزن أسراراً أو raw logs.
نهاية الجولة: سجّل الملفات والتغييرات، SHA الكود المختبر، أوامر الفحص وروابط CI، نتائج الهاتف إن وجدت، ما لم يثبت، العوائق والخطوة التالية. تحقّق من HEAD بعد الحفظ ومن اتساق الروابط. لا تدّع أن مهمة لاحقة ستعمل في الخلفية دون أداة فعلية.
عند تغيّر HEAD راجع التغييرات ولا تكتب فوق عمل آخر. لا تستخدم force-push ولا تعدّل غير feature/download-stability. لا تحذف بيانات أو تلغي عمل مستخدم. اقرأ AGENTS لحدود الأمان.
